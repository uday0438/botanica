# 🌱 Botanica - Smart Agricultural AI Platform

Botanica is a premium, AI-driven agricultural management dashboard designed to empower farmers with state-of-the-art diagnostics, real-time market telemetry, and precision soil analysis.


---

## ✨ Key Features

- **🔬 AI Crop Health Diagnostics**: Instantly identify plant diseases and get expert treatment solutions.
- **🛰️ Neural Field Monitor**: Real-time satellite-integrated telemetry for field health tracking.
- **💬 Doctor AI**: A specialized LLM-powered assistant for agricultural queries.
- **📈 Mandi Intelligence**: Real-time market price trends and demand forecasting.
- **🧪 Precision Soil Synthesis**: Accurate soil fertility scores and fertilizer recommendations.

## 🛠️ Technology Stack

- **Frontend**: React 19, TypeScript, Vite, Tailwind CSS 4
- **Backend**: Express.js (Vercel Edge Functions)
- **AI Engine**: Google Gemini 2.0 Flash
- **Styling**: Framer Motion, Lucide Icons, Shadcn UI
- **Data**: Integrated OpenWeather API & Kaggle-grounded datasets
